# Assets

Coloque nesta pasta os quatro arquivos de imagem atuais do repositório:

- `avatar.png`
- `favicon.png`
- `fundo.png`
- `preview.png`

Na branch `site-v2`, eles devem ficar em:

```text
assets/avatar.png
assets/favicon.png
assets/fundo.png
assets/preview.png
```

Não mantenha cópias duplicadas desses quatro arquivos na raiz após confirmar
que todas as referências do site estão funcionando.
