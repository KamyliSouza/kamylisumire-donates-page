V47.1 — HOTFIX DE ALINHAMENTO E COERÊNCIA DOS BOTÕES
======================================================

BASE
----
Aplicar sobre a V47:
- Blog Markdown
- Botões configuráveis por data/content/buttons.json
- Helper V47 compatível

OBJETIVO
--------
Corrigir desalinhamentos introduzidos pela troca de ícones fixos por SVGs
configuráveis, preservando a identidade visual específica de cada componente.

O hotfix NÃO força todos os botões a terem a mesma altura.
CTAs, filtros, abas, setas e botões da navbar continuam com dimensões
adequadas à sua função, mas passam a compartilhar a mesma lógica interna
de alinhamento entre ícone e texto.

CORREÇÕES
---------

1. Ícones configuráveis
- O tamanho passa a ser controlado por --button-config-icon-size.
- O slot do ícone e o SVG interno são tratados separadamente.
- Isso evita reduzir slots maiores, como os botões de doação.
- Ícones usam line-height: 0 para eliminar desalinhamento de baseline.

2. CTAs globais
- Ícones: 17px
- gap interno: 8px
- Texto e ícone centralizados de forma consistente.

3. Navbar / Apoiar
- Ícone: 16px no desktop.
- Ícone: 14px no mobile.
- O SVG respeita o contêiner existente da navbar.

4. Doações
- Os slots de 40px permanecem intactos.
- O SVG interno passa a 24px.
- LivePix e Pixie ficam visualmente equivalentes.

5. Ranking
- Remove a soma indevida de margin-right + gap.
- Ícone: 15px.
- gap: 6px.

6. Blog
- O filtro "Todos" agora é inline-flex.
- Ícone: 13px.
- gap: 5px.
- Remove margem extra que causava espaçamento desigual.

7. Links compactos da Home
- "Abrir no YouTube": ícone 14px / gap 5px.
- "Ver todas": ícone 14px / gap 6px.

8. Configurações do rodapé
- O botão de fechar volta a preservar a geometria quadrada de 32px.
- Remove padding/gap indevidos introduzidos na V47.
- Ícone de fechar: 16px.

9. Setas de Lives e Agenda
- SVG centralizado sem margin-top negativo.
- 21px desktop.
- 19px <= 700px.
- 18px <= 520px.
- Os círculos e estados disabled da V46.2 permanecem intactos.

10. Hidden states
- Ícone ou label configurados como vazios não deixam espaço residual.

APLICAÇÃO NO POWERSHELL
-----------------------

Na raiz do repositório:

    git apply --check V47-1-HOTFIX-ALINHAMENTO-BOTOES.patch

Se não aparecer nenhuma mensagem:

    git apply V47-1-HOTFIX-ALINHAMENTO-BOTOES.patch

Depois:

    py .github/scripts/validate-content.py

    Get-ChildItem .\js -Recurse -Filter *.js | ForEach-Object {
        node --check $_.FullName

        if ($LASTEXITCODE -ne 0) {
            throw "Erro de sintaxe em: $($_.FullName)"
        }
    }

    node --check .\workers.js

    git diff --check
